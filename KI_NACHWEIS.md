# KI-Nachweis

Der Code wurde von allen vier Gruppenmitgliedern mit KI-Unterstützung (Claude, Anthropic) erstellt. Die KI wurde
genutzt, um Code nach unseren Vorgaben zu erzeugen, Fehler zu suchen und Tests zu schreiben. Fachliche Vorgaben,
Datenbasis, Entwurfsentscheidungen sowie Prüfung und Korrektur der Ergebnisse lagen bei der Gruppe.
Wer welchen Teil verantwortet, steht im README (Kennzeichnung der Urheberschaft) und in der ersten Zeile jeder Datei.
